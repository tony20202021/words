# Учебный частотный словарь английского

Десять тысяч слов с переводами и транскрипциями. Заменяет прежний
`data/eng.json`, который оказался деловым: в нём не было ни «cat», ни «laugh»,
ни «hungry», ни «spoon», зато «the» и «The» лежали двумя записями, а «lie»
было переведено как «False».

## Что получилось

| | |
|---|---|
| слов | 10 000 |
| перевод из прежнего словаря | ~7300 |
| перевод сделан вручную | ~2700 |
| без перевода | 0 |
| с транскрипцией | 9994 |

## Данные

Всё в `../data/eng_freq/`:

- `frequency.txt` — список: ранг, слово, вид, откуда перевод;
- `translations.json` — переводы, сделанные вручную;
- `dropped.json` — выброшенное, с причиной у каждого слова;
- `names.txt` — подсказка по именам (только подсказка: половина английских
  имён это заодно слова — «grace», «rose», «mark», «will»);
- `eng10k.json` — готовый словарь в формате прежнего `eng.json`.
  **В репозитории его нет**: три мегабайта, и он целиком выводится из файлов
  выше одной командой (см. ниже). Соберите его перед работой;
- `rejected.json` — что отсеяли фильтры.

## Внешние источники

Оба скачиваются один раз и в репозиторий не кладутся — в репозиторий едет
результат, он и есть то, что надо воспроизводить.

**Частоты** — [wordfreq](https://pypi.org/project/wordfreq/) 3.1.1, сводный
список по восьми корпусам. Нужен один файл из колеса:
`wordfreq/data/large_en.msgpack.gz`. Пакет в окружение не ставится: `msgpack`
тоже не нужен, формат разбирает `wordfreq_reader.py`.

```bash
pip download wordfreq==3.1.1 --no-deps -d /tmp/wf
cd /tmp/wf && unzip -q wordfreq-3.1.1-py3-none-any.whl
```

**Транскрипции** — [ipa-dict](https://github.com/open-dict-data/ipa-dict),
125 927 английских слов с IPA, открытая лицензия:

```bash
curl -L -o /tmp/en_US.txt \
  https://raw.githubusercontent.com/open-dict-data/ipa-dict/master/data/en_US.txt
```

**Имена** — два открытых списка, нужны только для пометки «возможно имя»:
`dominictarr/random-name` и `hadley/data-baby-names`.

## Как пересобрать

```bash
# список: отсев мусора, добор из глубины, сверка с прежним словарём
python eng_tools/build_list.py --wordfreq /tmp/wf/wordfreq/data/large_en.msgpack.gz

# что осталось перевести
python eng_tools/batches.py status
python eng_tools/batches.py next --size 250        # порция на перевод
python eng_tools/batches.py add --file порция.json  # принять переведённое

# готовый словарь
python eng_tools/build_dictionary.py --ipa-dict /tmp/en_US.txt
```

Порядок важен: отброшенные вручную слова сборщик помнит и больше не берёт,
добирая список из глубины. Поэтому после каждой порции список пересобирают, и
процесс сходится — освободившиеся места занимают слова, которые раньше не
доставали до десяти тысяч. Так в словарь и попали «mushroom» и «carrot»:
в исходном корпусе они глубже десяти тысяч, потому что в интернете про морковь
пишут реже, чем про «championship».

## Чего в словаре нет

Четыре бытовых слова не дотянули и после всех итераций: `sock`, `scissors`,
`kettle`, `cucumber` — они глубже 12 500 в исходном корпусе. Если нужны,
их придётся добавить тематическим списком, а не частотой.

Шесть слов остались без транскрипции — их нет в ipa-dict: `remix`,
`midfielder`, `ebook`, `councillor`, `footballer`, `midfield`. Выдумывать
транскрипцию нельзя: неверную не видно, и это хуже отсутствующей.

## Что дальше

Транскрипции для новых слов собирает `word_transcription/` или прямо
`build_dictionary.py --ipa-dict`. Озвучка — `words/tts/gen_sounds.py`.
Загрузка в базу — обычным путём для словарей.
