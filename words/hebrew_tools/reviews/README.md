# Применённые правки словаря иврита

Здесь лежат правки, реально записанные в `hebrew_freq_10000_full.json`, по одному
файлу на прогон разбора.

## Зачем это тут

Сам словарь под `words/data/`, а этот каталог в `.gitignore` — 6.5 МБ JSON,
который переписывается целиком при каждой правке, в истории git только мешал бы.
Но тогда результат многодневной работы не имел бы ни одной копии вне рабочей
машины: `.bak` перезаписывается следующим же прогоном.

Эти файлы — компактный и восстановимый след. Каждая запись содержит ранг,
написание, поле, новое значение, обоснование и источники, так что по ним можно и
воспроизвести правку, и проверить решение задним числом, и увидеть, кто и почему
что-то поменял.

## Как применить заново

    python apply_review.py reviews/applied_201-400.json --apply
    python sync_hebrew.py --apply

`apply_review.py` идемпотентен: уже применённые правки он отмечает как «уже так»
и не трогает. Валидация выполняется в любом случае — она уже ловила и подмену
слова вместо огласовки, и правки, пронумерованные по порядку вместо ранга.

## Файлы

| файл | что это |
|---|---|
| `applied_001-200_pass1.json` | первый проход по рангам 1–200 |
| `applied_001-200_pass2.json` | второй, независимый проход по тем же словам: 20 правок, которых первый не нашёл |
| `applied_201-400.json` | ранги 201–400 |
| `applied_401-600.json` | ранги 401–600 |
| `applied_601-800.json` | ранги 601–800 |
| `applied_801-1000.json` | ранги 801–1000 |
| `applied_manual_followups.json` | ручные догоны: восстановленные ранги и парные правки перевода к омографам |
| `applied_disputed.json` | спорные правки, разобранные отдельным прогоном: из 60 применено 32, отклонено 13, 7 уже были применены |
| `applied_open_resolved.json` | те же 8 развилок, закрытые правилом «не уверен — показывай несколько вариантов» |

## Правило владельца словаря

Если уверенности в одном варианте нет — показывать несколько. Формат это
позволяет: несколько чтений одного написания идут в `tones` по строке на чтение,
несколько значений одного чтения — в `russian` через «;», основное первым.
Для изучения это полезнее угаданного одного варианта.

Исключение — часть речи: там один ярлык из закрытого набора, нескольких быть не
может. Здесь действует другое правило: формы одной леммы обязаны иметь одинаковый
ярлык, а расхождение внутри леммы хуже любого из выборов.

Отдельно, вне этих файлов, применялся `fix_ipa_stress.py` — системная починка
знака ударения, стоявшего внутри слогового начала (11 слов по всему словарю).
