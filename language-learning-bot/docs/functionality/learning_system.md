## Процесс изучения слов

### Изучение отдельного слова

Для каждого слова:

1. **Перевод слова** на русский язык
2. **Кнопки действий**:
   - "✅ Знаю, к следующему" - если знаете слово
   - "❓ Не знаю / не уверен, показать" - если не знаете

### Если знаете слово

1. Нажмите "✅ Знаю, к следующему"
2. Бот покажет слово на иностранном языке с транскрипцией
4. Кнопки:
   - "🔍 Показать крупное написание" - увеличенное изображение

## Режим выбора (пик-режим)

Включается настройкой **«Режим выбора (pick mode)»**. Вместо кнопок «Знаю / Не знаю» показывается несколько вариантов ответа — нужно выбрать правильный перевод, иероглиф или транскрипцию.

### Как работает

1. Показывается исходное слово (например, транскрипция или иероглиф)
2. Под ним — N вариантов ответа + кнопка «Не знаю»
3. После выбора слово раскрывается и появляется **результат**:
   - **Зелёный баннер** «✓ Правильно!» — верный ответ (веб, Android) / отдельное сообщение (Telegram)
   - **Красный баннер** «✗ Неверно» — ошибка или «Не знаю» (веб, Android) / отдельное сообщение (Telegram)
4. После неверного ответа появляется кнопка **«🚫 Не показывать такую комбинацию»** — убирает именно эту пару «слово+дистрактор» из будущих вопросов

### Модальности

| Показывается (источник) | Нужно выбрать (цель) |
|-------------------------|----------------------|
| Иероглиф / иностранное | Перевод, транскрипция |
| Транскрипция | Иероглиф, перевод |
| Перевод | Иероглиф, транскрипция |

### Дистракторы

- Берутся случайно из изученных слов, более ранние слова (малый номер) встречаются **чаще** по логарифмической шкале: слово #10 в 2x реже слова #1, #100 — в 3x, #1000 — в 4x
- **Фильтр по количеству единиц:** когда источник — иероглиф или транскрипция, все варианты ответа содержат одинаковое число единиц с правильным ответом (чтобы нельзя было угадать подсчётом). Для китайских иероглифов считаются **символы**, для остального текста — **слова через пробел**

## Система интервального повторения

### Как работают интервалы
```
Знаете слово:    1 день → 2 дня → 4 дня → 8 дней → 16 дней → 32 дня (по умолчанию)
Не знаете слово: → возврат к 1 дню
```

Максимальный интервал регулируется настройкой **max_check_interval** (по умолчанию 32). Можно увеличить, чтобы хорошо известные слова повторялись реже.

### Настройки сессии

| Настройка | Назначение | По умолчанию |
|-----------|------------|--------------|
| `reset_session_days` | Сброс по дням (+ часам) | 1 |
| `reset_session_hours` | Часовая компонента сброса | 6 |
| `unknown_limit_new_words` | Лимит ошибок до рекомендации рестарта | 10 |
| `max_check_interval` | Максимальный интервал повторения (дни) | 32 |

#### Логика сброса сессии

Сессия считается устаревшей когда прошло **одновременно**:
- calendar-day разница ≥ `reset_session_days`
- часовая компонента timedelta ≥ `reset_session_hours`

Пример: учился вчера в 22:00, сейчас 05:00 → 1 календарный день, 7 часов → сессия устарела.

При устаревшей сессии показывается предупреждение-баннер. Сессия не удаляется — пользователь сам выбирает: продолжить или нажать «Начать заново».

#### Рекомендация рестарта при лимите ошибок

Когда текущее слово вышло за пределы изученных (`word_number >= words_studied`) и количество ошибок в сессии достигло лимита `unknown_limit_new_words` — показывается уведомление с рекомендацией перезапустить сессию.

Система учитывает:
- Правильность ответов

## Система подсказок

Персональные ассоциации для лучшего запоминания **любых языков**.

### Типы подсказок (универсальные)

#### 🧠 Ассоциации на русском
Связывайте слово с русскими образами:
- Китайский "谢谢" → "Се-се, как шепчешь спасибо"
- Арабский "شكرا" → "Шукран как сахар - сладкое спасибо"

#### 💡 Фонетические ассоциации  
Звуковые ассоциации с русскими словами:
- Японский "ありがとう" → "Аригато, как робот говорит"
- Тайский "ขอบคุณ" → "Куп-кун, как звук падения"

#### ✍️ Ассоциации для написания
Помощь с запоминанием написания **любых алфавитов**:
- Китайский "学" → "Ученик под крышей изучает руками"
- Арабский "كتاب" → "Волнистые линии как страницы книги"

#### 🎵 Звучание по слогам
Разбивка сложных слов на части.

### Интеграция с AI
- Визуальное + текстовое запоминание
- **Автоматические ассоциации** на основе AI анализа (планируется)
