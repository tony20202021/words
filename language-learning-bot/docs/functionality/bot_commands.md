# Команды Telegram-бота

## Пользовательские команды

| Команда | Описание |
|---------|----------|
| `/start` | Главное меню: статистика, выбор языка |
| `/study` | Продолжить текущую сессию (не сбрасывает прогресс) |
| `/restart` | Начать заново — сброс сессии и старт с первого слова |
| `/language` | Сменить язык для изучения |
| `/settings` | Настройки процесса обучения |
| `/stats` | Статистика по всем языкам + графики (3 группы) |
| `/web` | Ссылка на веб-версию с одноразовым кодом + QR-код |
| `/android` | QR-код ссылки скачивания + APK-файл |
| `/connect_android` | Одноразовый код для входа в Android-приложение |
| `/help` | Справка |

## Процесс изучения

После `/study` или `/restart` бот показывает карточку слова с кнопками:

**До ответа:**
- **Знаю** — слово известно, переходит к следующему
- **Показать** — показать перевод и транскрипцию
- **Пропустить** — пометить слово (скрывается если `show_skip_button=False`)

**После показа ответа:**
- **К следующему** — интервал повторения удваивается
- **Ой, не знаю** — интервал сбрасывается до 1 дня
- **Пропустить** — пометить слово

**Дополнительно:**
- 🔊 — кнопки воспроизведения звука
- 💡 Подсказки — управление ассоциациями

### Числовые параметры
| Параметр | Описание |
|----------|----------|
| Начальное слово | Номер слова, с которого начинается сессия |
| Сброс сессии (дни) | Через сколько дней сбросить сессию автоматически |
| Сброс сессии (часы) | Через сколько часов сбросить сессию автоматически |
| Лимит неизвестных слов | Макс. количество новых слов за сессию |

## Административные команды

| Команда | Описание |
|---------|----------|
| `/admin` | Административная панель |
| Управление языками | Создание, редактирование, удаление языков |
| Управление словами | Поиск, редактирование, удаление слов |
| Управление пользователями | Список пользователей, назначение прав |
| Рассылка | Отправка сообщений всем пользователям |
| Диагностика | Статус сервисов |
| Импорт | Загрузка XLSX/CSV/JSON со словами |
| Экспорт | Выгрузка словаря в XLSX/CSV/JSON |

## Интервальное повторение

- «Знаю» → интервал × 2: 1 → 2 → 4 → 8 → 16 → 32 дня
- «Не знаю» → интервал сбрасывается до 1 дня
- Дата следующего повторения рассчитывается от текущего дня
